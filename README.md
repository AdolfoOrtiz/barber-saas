# Barber SaaS

Barber SaaS es una plataforma web multi-tenant desarrollada con Django que permite la **gestión y reserva de citas en barberías locales**.  

El sistema está diseñado para funcionar bajo un modelo de suscripción, donde las barberías pueden registrar sus sucursales y servicios, mientras los barberos gestionan sus perfiles profesionales, portafolios de cortes y horarios de disponibilidad.  

Los clientes pueden explorar barberías en la ciudad, consultar perfiles de barberos, ver estilos anteriores y agendar citas en línea de manera sencilla y organizada.  

La arquitectura del proyecto asegura la **portabilidad del barbero**, permitiendo que su perfil y portafolio sean independientes de la barbería en la que trabaje, manteniendo su historial y reputación aunque cambie de afiliación.  

Este proyecto busca ofrecer una solución SaaS escalable, modular y profesional para la industria de barberías, integrando roles de usuario, control de permisos y validación de citas sin solapamientos.
